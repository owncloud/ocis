Change: Default 30-day expiration for personalized shares

When a user or group share of a file or folder is created without an
expiration date, the server now preconfigures a default expiration of 30 days
to encourage data minimization. The sharer can override or shorten this value.

Space memberships are exempt and stay unbounded, as they represent a permanent
organizational role.
