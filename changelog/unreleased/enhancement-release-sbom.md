Enhancement: Add SBOMs to releases

Every release now includes Software Bills of Materials: `ocis-<version>.spdx3.json` in SPDX 3.0.1 format and
`ocis-<version>.cdx.json` in CycloneDX format (generated by Trivy).
The SPDX file lists the Go and npm dependencies with version, package URL, hash, supplier, declared license and
copyright statements. It is generated by the new `tools/sbomgen` with the official SPDX tools-golang
library, and validated before it is published.

https://github.com/owncloud/ocis/pull/13600
