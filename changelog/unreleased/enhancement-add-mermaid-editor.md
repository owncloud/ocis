Enhancement: Add Mermaid diagram editor

Added a dedicated split-pane editor and live preview for standalone Mermaid
diagram files (`.mmd`/`.mermaid`). Previously Mermaid rendering only worked
inside a fenced code block of a Markdown document; there was no way to edit
a diagram on its own without wrapping it in Markdown first.
