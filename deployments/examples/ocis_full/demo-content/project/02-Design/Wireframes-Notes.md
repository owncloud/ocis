# Wireframe Notes — Reviewer Portal

## Review Queue (landing page)

- Table of pending documents: title, submitter, due date, priority
- Filter by status (Pending / In Review / Approved / Rejected)
- Sort by due date by default

## Document Detail View

- Inline preview (PDF/Office) on the left
- Decision panel on the right: Approve / Reject / Request Changes
- Comment thread below the preview, threaded by section
